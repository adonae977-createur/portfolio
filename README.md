# Portfolio — Rodrigue Donatien Sawadogo

Portfolio professionnel : entrepreneur, développeur web & PWA, gestion de projets, sport & technologie, menuiserie & agencement.

Statut : **en construction** (étape 1/8 — scaffold).

## Stack

- React 18 + Vite 5
- Tailwind CSS v4
- React Router
- Firebase Hosting (déploiement)

## Développement local

```powershell
npm install
npm run dev
```

## Build de production

```powershell
npm run build
npm run preview
```

## Déploiement (à venir)

```powershell
firebase deploy --only hosting
```

Documentation complète (architecture, contenu, mise à jour) à ajouter en fin de projet.
